🎓 IIT College Placement Analysis

A data analysis project comparing IIT placement trends using average package, highest package, placement rate, branches, and recruiters.

📊 Features-

- IIT-wise placement comparison
- Average & highest packages
- Branch-wise analysis
- Placement rate
- Top recruiters
- Excel dashboard

🛠️ Tools-

Microsoft Excel • Data Analysis • Data Visualization • GitHub

🎯 Objective-

To turn placement data into clear insights that help students understand and compare IIT placement performance.
